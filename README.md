## Getting started

The Blueprint is an overlay, not an app skeleton. To start building:

1. Scaffold the app in a fresh empty folder (create-next-app, Vite, etc.).
2. Overlay these Blueprint files onto it.
3. Run `/onboard` (or `$onboard`) to tune commands and conventions to the stack.
4. Fill in [blueprint/project-plan.md](blueprint/project-plan.md) and
   [blueprint/build-plan.md](blueprint/build-plan.md), then run `/overview`.

Commands will be documented here once the app is scaffolded.
